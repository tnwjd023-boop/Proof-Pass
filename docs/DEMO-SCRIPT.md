# 3분 발표 대본 · Private authorization + execution-time revocation

## 첫 30초

“에이전트에게 돈을 쓸 권한을 줬다가 회수했습니다. 이미 발급한 미사용 승인도 막을 수 있을까요? ProofPass는 신원과 전체 한도를 지급 체인에 공개하지 않고 요청을 승인하며, 실제 지급 시점에 권한을 다시 확인합니다. 여기서는 0.05 SOL이 실제 지급됐고, 별도 승인은 자격 삭제 반영 후 만료 전에도 거절됐습니다. 추가 지급은 0입니다.”

메인 카피: **Prove permission privately. Enforce it at execution.**

아래는 **2026-09-21 Midnight Preprod 저장 실행**을 설명하는 대본입니다. 먼저 화면의 완료 시각을 짚고 과거 기록임을 말합니다. 새 실행 중에도 아래에는 마지막 완료 기록이 남으므로 지금 만든 proof나 현재 유효한 자격이라고 설명하지 않습니다.

## 증거와 영상 사용

- [전체 실행](../evidence/preprod/live-flow.json)의 지급은 50,000,000 lamports, 승인 소비는 true입니다. [대시보드 기록](../evidence/preprod/dashboard-run.json)도 동일 지급 서명을 가리킵니다.
- 해당 실행의 지급용 proof 생성은 7.738초, 승인 요청부터 목적지 등록까지 42.283초입니다. 지갑 준비 제외 전체 흐름은 221.699초로, 위 3분은 저장 기록을 설명하는 발표 길이입니다. 실시간 전체 실행이 3분 안에 끝난다는 의미가 아닙니다.
- 새 실행을 촬영한다면 proof 생성·확정·지갑 준비 대기를 생략하거나 배속 처리한 구간에 **“대기 구간 편집”** 또는 배속을 표시합니다. 저장 기록과 새 실행 화면을 섞어 성공을 연출하지 않습니다.
- 기존 [영상 플레이어](../evidence/demo/watch.html)는 **Midnight 로컬 네트워크** 실행을 1.4배속으로 재생한 자료이며 Preprod 실행 영상이 아닙니다. 이번 UI와 화면도 다릅니다.

## 질문에 대한 짧은 답

- **기업 AI Agent 권한도 되나요?** 조직 → 담당자 → AI Agent → 외부 서비스는 Roadmap / Next experiment입니다. 현재는 개인 위임과 authorized signer이며 조직 재위임·상위 담당자 권한 회수는 구현되지 않았습니다.
- **실패 거래에도 수수료가 있나요?** “0 SOL moved”는 보호된 vault에서 수신자로의 지급이 0이라는 의미입니다. 실패 거래의 수수료까지 0이라고 주장하지 않습니다.

- **중앙 서버도 개인정보를 숨길 수 있지 않나요?** 맞습니다. 여기서는 서버 판단을 신뢰하는 것에 더해, 신뢰된 서명 근거와 비공개 입력에 대한 정해진 정책 계산을 증명합니다. 어댑터와 릴레이의 신뢰까지 제거하지는 않습니다.
- **개인정보가 어디로 가나요?** 원본 신원은 로컬 환경·신원 어댑터가, 서명 근거와 비공개 위임은 로컬 prover가 처리합니다. 브라우저 지갑·모바일 지갑 통합은 미구현입니다.
- **삭제 즉시 막히나요?** 아닙니다. 목적지 상태에 반영된 뒤의 차단을 검증했습니다. 최대 60초의 상태·승인 lease가 적용됩니다.
